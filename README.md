# Snackify – Online Snack Shop

Snackify is a responsive online snack shop website designed to present a wide variety of snacks in an attractive and user-friendly layout. The project focuses on creating a modern product-based website using HTML and Tailwind CSS.

## About the Project

Snackify provides an engaging browsing experience with snack categories, product collections, special offers, customer reviews, and other useful sections. The responsive design allows the website to adapt smoothly to different screen sizes.

## Features

* Responsive navigation bar
* Attractive hero section
* Snack categories
* 30+ snack products
* Product cards with images and prices
* Best-selling snacks section
* Combo offers
* Snacks under ₹100 section
* Customer reviews
* Why Choose Us section
* Newsletter subscription
* Responsive design for mobile, tablet, and desktop
* Clean and modern footer

## Technologies Used

* HTML5
* Tailwind CSS
* Responsive Web Design
* Unsplash Images

## Design

The website uses a warm snack-inspired color palette with orange, cream, and dark brown shades to create an attractive food-shop appearance. The layout is designed to keep products and offers easy to explore.
